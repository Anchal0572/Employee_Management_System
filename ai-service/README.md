# EMS AI Service Layer

This microservice provides an isolated, decoupled intelligence layer for the Employee Management System.

## Responsibilities
- Resume parsing and candidate skill scoring
- Intelligent employee performance review analysis
- Automated policy Q&A assistant
- Attrition risk prediction and sentiment analysis

## Phase Roadmap
- **Phase 1**: Architecture isolation, configuration, and health status interface.
- **Phase 2**: Event-driven hooks connecting to the primary EMS backend.
- **Phase 3**: Integration with LLM providers (Gemini / OpenAI) with prompt engineering and vector embeddings.
